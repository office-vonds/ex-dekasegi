よくある質問

はじめて使う方へ

本当に無料ですか？
基本機能（つぶやき閲覧／AI bot 相談／投稿）は永久無料です。月額制ツール（写メ日記AI 等）は希望者のみご利用ください。
身バレしませんか？
本名・電話番号・メールアドレス・LINE ID 等の本人特定情報は一切収集しません。ブラウザの匿名 ID のみで利用できます。投稿はすべて運営チームが目視チェックし、お店/個人が特定される投稿は非公開化します。
未経験でも参加できますか？
もちろん可能です。「これから出稼ぎを始めたい」「初めての店選びで失敗したくない」という方のための bot です。
店舗側からの投稿はどう見分けるの？
運営側で IP・投稿パターン・文体を分析し、ステマ／関係者投稿は除外します。怪しい投稿は「未承認」表示で透明化します。
悪質店を晒すって法的に大丈夫？
事実に基づく注意喚起・契約と異なる実態の共有のみ受け付けます。誹謗中傷・個人攻撃は削除対象です。詳細は利用規約をご確認ください。
運営者について

業界 22 年。
「先に失敗した側」が運営しています。

本サイトは 2003 年に国内最初期の風俗出稼ぎ専門メディアを立ち上げた運営チームが、業界 22 年の経験と当事者からの相談蓄積を元に運営しています。

運営者個人の氏名は、相談者・投稿者の安全を最優先するため、また投稿の公平性を担保するため、意図的に非公開としています。「誰が運営しているか」より「何が書かれているか」で判断してください。

当時、出稼ぎ専門サイトは国内に存在せず、出稼ぎ嬢が信頼できる情報にアクセスする手段がほとんどありませんでした。その後大手ポータル・求人媒体が参入し市場は拡大しましたが、「広告費を払う店舗側に都合のいい情報」ばかりが上位に並ぶ構造は今も変わっていません。

本サイトは広告主側ではなく、「先に失敗した嬢」「現役で稼ぎ続ける嬢」の側に立ち、匿名つぶやきと AI bot で「本当の現場情報」を再び嬢の手に戻すために運営しています。

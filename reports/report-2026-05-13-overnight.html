🎯 残・NOYUTO 動員 (合計 120 秒)

1

DNS 切替: ex-dekasegi.jp → Cloudflare Pages

所要 60秒 / お名前.com で操作
  1. お名前.com にログイン → ドメイン一覧 → ex-dekasegi.jp
  2. 「DNSレコード設定」→ A レコードを以下に追加 (CNAME より A 推奨):
    ホスト名: @ / TYPE: CNAME / VALUE: ex-dekasegi.pages.dev
    ホスト名: www / TYPE: CNAME / VALUE: ex-dekasegi.pages.dev
  3. 保存 → CF Pages 側「Custom domains」で ex-dekasegi.jp 追加 (これは私が朝にやる・NOYUTO は DNS だけでOK)
Why: 現在 ex-dekasegi.jp は旧 WPX サーバー (PHP 8.2 で Fatal error) を指している。DNS を CF Pages に切替えれば即座に新サイトが ex-dekasegi.jp で見える。.htaccess リダイレクトは中間つなぎ。
2

GA4 property 作成: ex-dekasegi.jp

所要 60秒 / GA4 UI で操作
  1. analytics.google.com → 管理 → アカウント「絆ILゲーム」(UNRYUTO 帰属) を選択
  2. 「プロパティを作成」→ 名前: ex-dekasegi.jp / タイムゾーン: 日本 / 通貨: JPY / 業種: 仕事と教育
  3. データストリーム作成 → ウェブ → URL: https://ex-dekasegi.jp / 名称: ex-dekasegi.jp (web)
  4. 発行された Measurement ID (G-XXXXXXX) を NOYUTO が私に伝える → 私が public/index.html の G-XXXXXXX 1 line を差替えて再 deploy (3 分)
Why: GA4 Admin API は Service Account に property 作成権限が無い (read-only 限定)。これは UI 必須。gtag コードは既に index.html に仕込み済で、ID 確定後 1 line 差替で完成。

※ 上記 2 件は順不同。DNS 切替後 GA4 を作るのが推奨 (本番 URL で計測スタート)。

📚 黄金律の物証: bot 知識辞書サンプル

NOYUTO 直命「情報の質と信憑性さえ外さなければシンプルに勝てる」を実装に落とした結果。実際の bot 応答 (再現可能):

USER 質問
「罰金制度のある店に応募しちゃった。どうしたらいい？」
AI BOT 応答 (実際の本番出力)

1. ユーザーの不安/質問を 1 行で要約
応募した店が罰金制度を導入しているのでどうしたらいい？

2. 該当する悪質パターン
⚠️ 罰金/違約金/ペナルティ (根拠: 労基法違反の可能性)

3. 店に確認すべき具体ポイント
- 罰金制度の内容と範囲を明確に説明してください。
- 罰金制度の適用基準と計算方法を説明してください。
- 罰金制度はどのような場合に適用されますか。
- 罰金制度はどのように解除または減免されるかを説明してください。

4. 相談リソース番号を提示
- 法テラス (無料法律相談): 0570-078374 (罰金返還・契約解除・労働問題)

ChatGPT 直書きの「無難な励まし」では絶対に出てこない構成。違法パターン辞書 + 根拠法律 + 公的相談先電話番号まで構造化済。これが「黄金律の物証」。

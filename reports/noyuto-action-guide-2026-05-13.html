1

GA4 プロパティ作成所要 60秒

解析開始の起点。測定ID (G-XXXXXXXXXX) を取得して pochi に渡せばOK。

  1. 下記URLを開く。
    https://analytics.google.com/
  2. 左下の歯車アイコン (管理) をクリック → アカウント欄から 「絆ILゲーム」 を選択。
  3. 右側「プロパティ」列の 「+ プロパティを作成」 をクリック → 下記を入力:
    プロパティの詳細
    プロパティ名ex-dekasegi
    レポートのタイムゾーン日本
    通貨日本円 (JPY ¥)
    「次へ」 をクリック。
    ビジネスの詳細・ビジネス目標は 「コミュニティ」「ユーザー行動の調査」 を選択して 「作成」。
  4. データストリーム選択画面で 「ウェブ」 をクリック → 下記を入力:
    ウェブストリームの設定
    ウェブサイトのURLhttps://ex-dekasegi.jp
    ストリーム名ex-dekasegi web
    「ストリームを作成」 をクリック。
  5. 作成された画面の右上に表示される 測定ID (例: G-ABC123XYZ) をコピー。
納品測定ID (G-で始まる文字列) を pochi にチャットで渡す。pochi が30秒で HTML に差し込み + 本番再 deploy までやる。
2

Search Console プロパティ追加所要 60秒

Step 1 完了後すぐ。GA4 連携で1発verify。検索順位とインデックス監視の起点。

  1. 下記URLを開く。
    https://search.google.com/search-console
  2. 左上の 「プロパティを追加」 ボタン (または既存プロパティのプルダウンから「+プロパティを追加」) をクリック。
  3. 「URLプレフィックス」 側 (右側のボックス) に下記を入力 → 「続行」 をクリック:
    https://ex-dekasegi.jp/
    ※ 末尾 / 必須・スラッシュ忘れると別プロパティ扱いになる。
  4. 確認方法の選択画面で 「Google Analytics」 をクリック。
    Step 1 の GA4 が同じ Google アカウントなら 「所有権を確認しました」 と即表示される。
  5. 「プロパティに移動」 をクリック → pochi に「GSC 登録完了」と一言チャット。
verify が GA4 経由で通らない場合のみ: 確認方法画面で「HTMLファイル」を選び、表示された google-XXXXXXXXX.html のファイル名を pochi に渡す。pochi が30秒で配置 deploy する。
納品「GSC 登録完了」のチャット1行で OK。pochi が即sitemap.xml提出 + index status監視まで自動化する。
3

お名前.com で DNS 切替所要 60秒

独自ドメイン ex-dekasegi.jp を Cloudflare Pages に向ける最終操作。これが完了したらサイトが ex-dekasegi.jp で表示される。

  1. 下記URLを開く・ログイン。
    https://www.onamae.com/navi/login.html
  2. 上部メニュー 「ドメイン」 → 「ドメイン機能一覧」 → 「DNS関連機能の設定」 → 一覧から ex-dekasegi.jp にチェック → 「次へ」。
  3. 「DNSレコード設定を利用する」 の右端「設定する」をクリック。
  4. 既存のAレコード・CNAMEレコードがあれば一旦すべて 「削除」 (右端のゴミ箱アイコン)。
    ※ 旧Xサーバー向けレコードの掃除。残ってると優先順位の競合が起きる。
  5. 新しいレコードを2つ追加:
    レコード A (ルートドメイン)
    ホスト名空欄のまま (またはアットマーク)
    TYPECNAME
    VALUEex-dekasegi.pages.dev
    TTL3600 (デフォルト)

    レコード B (www. 経由対策)
    ホスト名www
    TYPECNAME
    VALUEex-dekasegi.pages.dev
    TTL3600 (デフォルト)
  6. 「確認画面へ進む」 → 「設定する」 で確定。
    DNS Preview のチェックがあれば外す (上書き上書きで競合する場合あり)。
  7. pochi にチャットで 「DNS切替完了」 と一言。
反映時間: 通常 5分〜2時間で全世界反映。最大24時間。
確認方法: pochi が dig ex-dekasegi.jp +short で5分おき監視・反映確認次第 Cloudflare Pages カスタムドメイン設定 + SSL証明書発行まで自動化する。
納品「DNS切替完了」の1行チャットで OK。pochi が即 Cloudflare 側のカスタムドメイン登録・SSL自動発行・最終疎通確認まで完遂する。

3 ステップ完了後の自動化フロー (pochi 側)

NOYUTO が3分で渡した結果を起点に、pochi 側で完全自動化:

1. 測定ID差込 2. wrangler 再deploy 3. GSC sitemap提出
4. CF Pages カスタムドメイン設定 5. SSL証明書発行確認
6. index status 監視cron 起票 7. 24h後 初期データ報告HTML
